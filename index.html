Desjardins · Retrouver un écart de réconciliation

J’ai automatisé les tests de qualité et comparé les données sources aux données transformées avant leur mise en production. J’ai aussi documenté leur parcours pour les audits financiers.

Démonstration SQL

Le lot fictif A contient deux écritures de 60 et 40 dollars. Le contrôle signale les 5 dollars manquants dans le total transformé.

WITH ecritures AS (
  SELECT * FROM (VALUES ('A', 60), ('A', 40)) v(lot, montant)
), rapport AS (
  SELECT 'A' AS lot, 95 AS total
)
SELECT e.lot, SUM(e.montant) - r.total AS ecart
FROM ecritures e JOIN rapport r ON e.lot = r.lot
GROUP BY e.lot, r.total
HAVING SUM(e.montant) <> r.total;
